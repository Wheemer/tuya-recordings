# Security Policy

## Supported versions

Security fixes are made against the latest released version of Tuya Recordings.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting form for this repository:
https://github.com/Wheemer/tuya-recordings/security/advisories/new

Include the affected version, a clear reproduction or proof of concept, and any
relevant logs with secrets removed. We will acknowledge the report privately,
investigate it, and coordinate a fix before public disclosure.
